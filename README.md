# Python

This repository contains a collection of Python scripts and small projects.

## 拳皇

`拳皇/` is a `pygame` 2D fighting game project.

Run it from the project root:

```powershell
python 拳皇/gayforce.py
```

Or open the folder in VS Code and press `F5`.

## Environment

- Python 3.11+
- `pygame` 2.6.1

Install dependencies:

```powershell
pip install -r 拳皇/requirements.txt
```
