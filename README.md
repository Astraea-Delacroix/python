# 拳皇

一个基于 `pygame` 的 2D 对战游戏项目。

## 运行

```powershell
python gayforce.py
```

如果你在 VS Code 里打开项目，直接按 `F5` 也可以。

## 环境

- Python 3.11+
- `pygame` 2.6.1

安装依赖：

```powershell
pip install -r requirements.txt
```

## 操作

- 主菜单：鼠标点击，或 `Up/Down + Enter`
- 选人页：鼠标点击角色，或
  - P1：`WASD + Enter`
  - P2：方向键 + 小键盘 `Enter`
- 对局：键盘操作

## 说明

项目资源使用相对路径，但入口脚本会自动切到项目根目录，因此可以直接运行 `gayforce.py`。
