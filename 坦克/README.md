# 坦克大战游戏

## 游戏简介
这是一个使用Python和Pygame开发的经典坦克大战游戏。

## 游戏特性
- 玩家坦克（绿色）
- 敌方坦克AI（红色）
- 多种障碍物：砖墙（棕色，可被摧毁）、钢墙（灰色，不可摧毁）
- 基地保护系统（黄色基地）
- 子弹射击系统
- 分数统计
- 生命系统
- 游戏胜利/失败判定

## 操作说明
### 移动控制
- **W** 或 **↑**: 向上移动
- **S** 或 **↓**: 向下移动
- **A** 或 **←**: 向左移动
- **D** 或 **→**: 向右移动

### 游戏操作
- **空格键**: 发射子弹
- **R键**: 游戏结束后重新开始

## 游戏规则
1. 消灭所有敌方坦克（共20辆）即可获胜
2. 保护基地不被摧毁（基地生命值：3）
3. 玩家有3条生命
4. 每击毁一辆敌方坦克获得100分
5. 屏幕上最多同时出现5辆敌方坦克

## 运行要求
- Python 3.6+
- Pygame库

## 安装依赖
```bash
pip install pygame
```

## 运行游戏
```bash
cd D:\python\坦克
python tank_game.py
```

## 游戏对象说明
- **绿色坦克**: 玩家控制的坦克
- **红色坦克**: 敌方AI坦克
- **棕色方块**: 砖墙（可被子弹摧毁）
- **灰色方块**: 钢墙（不可摧毁）
- **黄色方块**: 基地（必须保护）
- **黄色小点**: 子弹

## 开发信息
- 开发语言: Python
- 游戏引擎: Pygame
- 屏幕分辨率: 800x600
- 帧率: 60 FPS
